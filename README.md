# PatchContext - GitHub Repository RAG Assistant

## Overview
PatchContext is a Retrieval-Augmented Generation (RAG) application that allows users to chat with GitHub repositories using AI. It retrieves relevant code context from the repository and generates accurate responses using LangChain, FAISS, Ollama, and Streamlit.

## Features
- GitHub Repository Analysis
- Context-aware Question Answering
- FAISS Vector Database
- LangChain Integration
- Ollama LLM
- Streamlit User Interface

## Tech Stack
- Python
- LangChain
- FAISS
- Ollama
- Streamlit
